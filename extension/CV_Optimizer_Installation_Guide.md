# 🚀 CV Optimizer 測試版安裝教學

感謝您協助測試 **CV Optimizer (版本 1.0.3)**！

這是一份給測試人員的專屬指南，教您如何在 Google Chrome 瀏覽器中，手動安裝尚未在 Web Store 上架的最新測試版擴充功能。

---

## 📦 1. 準備工作

您應該已經從開發者那裡收到一份名為 `dist.zip` (或類似名稱) 的壓縮檔案。

1. **請將該壓縮檔解壓縮**。
2. 解壓縮後，您會獲得一個名為 `dist` 的資料夾。
3. **重要**：請將這個 `dist` 資料夾放置在一個您「不會輕易刪除」的地方（例如：我的文件、桌面專門的資料夾裡）。**一旦安裝完成，這個資料夾不能被刪除或移動，否則擴充功能將會失效。**

---

## 🔧 2. 安裝步驟指引

### 步驟 2.1：進入 Chrome 擴充功能管理頁面
1. 開啟您的 **Google Chrome** 瀏覽器。
2. 在網址列輸入以下網址並按下 `Enter` 鍵：
   > `chrome://extensions/`

### 步驟 2.2：開啟「開發人員模式」
1. 在擴充功能頁面的**右上角**，您會看到一個名為 **「開發人員模式 (Developer mode)」** 的開關。
2. 請點擊該開關將其**開啟**（開關會變成藍色）。
3. 開啟後，頁面左上方會多出一排按鈕（載入未封裝項目、套件擴充功能、更新）。

### 步驟 2.3：載入擴充功能資料夾
1. 點擊頁面左上角的 **「載入未封裝項目 (Load unpacked)」** 按鈕。
2. 在彈出的檔案選擇視窗中，找到您在「準備工作」中解壓縮出來的那個 **`dist`** 資料夾。
3. 點選該資料夾後，點按「選取」或「開啟」。

### 步驟 2.4：確認安裝與固定圖示
1. 如果步驟正確，您現在應該能在此頁面的列表中，看見 **CV Optimizer Side Panel** (1.0.3 版) 的卡片。
2. 為了方便使用，請點擊 Chrome 視窗右上角的「拼圖」圖示 (擴充功能選單)。
3. 在選單中找到 **CV Optimizer Side Panel**，並點擊旁邊的「大頭針」圖示將其**釘選**。
4. 現在，您可以點擊該圖示開始使用了！🎉

## 💡 3. 常見問題與注意事項

* **為什麼會跳出「錯誤」的紅色按鈕？**
  這在開發人員模式下很常見。只要擴充功能的功能正常運作，您可以暫時忽略它。

* **安全性與隱私疑慮？**
  請放心，此擴充功能不會收集您的無關個資。所有用來呼叫 AI 的 API 金鑰 (例如 Gemini) 皆受後端伺服器保護，並無安全性疑慮。

* **測試結束後？未來如何更新？**
  由於這只是手動載入的測試版，未來**無法自動更新**。當開發者通知您正式版已於 Web Store 上架後：
  1. 請回到 `chrome://extensions/` 頁面，點選我們剛安裝的測試版卡片上的 **「移除 (Remove)」** 按鈕。
  2. 接著前往 Chrome Web Store 搜尋並下載最新的正式版。
